# 月面采集站操作手册

[简体中文首页](../README.md) · [English field manual](controls.md)

用支持 WebGL 2 的浏览器打开单文件 HTML，在首页选择 **开始完整任务**。首页和暂停菜单均可打开 **设置**。

## 电脑操作

| 操作 | 功能 |
| --- | --- |
| `W` / `↑`、`S` / `↓` | 前进或倒车 |
| `A` / `←`、`D` / `→` | 向左或向右转向 |
| `空格` | 刹车并让车身停稳 |
| 前进时按住 `Shift` | 推进 |
| 移动鼠标 | 鼠标锁定时转动视角。需要重新启用鼠标视角时点击游戏画面。 |
| 靠近晶石、仪器或观测站时长按 `E` | 根据提示取样、读取仪器或校准观测站 |
| 在地球观测台轻按 `E` | 停稳后打开望远镜 |
| `R` | 在工坊制造套件。在施工点预览地基，再按一次启动安装。 |
| `Esc` 或 `P` | 暂停并释放鼠标。选择 **继续任务** 恢复驾驶。 |

## 触屏操作

- 左侧摇杆上推前进、下拉倒车、左右转向。松手即刹车。
- 在画面右半边的空白处拖动，可转动视角。
- 长按 **推进** 获得额外动力。摇杆松开时，单独长按推进也能向前开。
- 按 **刹车** 停车。车已停稳且摇杆松开时，长按 **刹车** 可倒车。
- 可操作的目标附近会显示交互按钮，点一下即可开始。建造时先点一下预览地基，确认位置合适后再点一次安装。
- 点击暂停图标打开菜单。浏览器支持全屏时，游戏会在开始或继续任务时请求全屏，也可在 **设置** 中切换。

## 完整任务流程

1. 在晶石和勘测仪旁停车操作。雷达上的实心点标记晶样，空心点标记仪器。收集 **两份晶样和两份勘测读数**，回着陆区停稳，上传初勘记录。
2. 到工坊停车，按 `R` 或点击 **制造**。把套件带到中继施工点，预览地基。如果车占住安装位置，先挪开再启动安装。机械臂开始放置套件后，等它完成。
3. 采集 **第三份晶样**，回工坊制造地形观测站套件，选择可用地基部署。等观测站完成通电自检，停稳后长按 `E` 或点校准按钮完成首次读数。
4. 制造并安装太阳能补给站。停进补给站范围可以补电，之后返回着陆区回传任务数据。

采样提示要求给机械臂留出净空时，先挪车再停稳操作。岩芯入舱后再开车。注意避开巡逻机的扫描光束，被扫到会扣除任务时间。

## 地球观测

雷达上的 **浅紫色菱形** 标记地球观测台。停稳后按 `E` 或点 **观测地球**。拖动调整取景，用滚轮或双指缩放，用两侧箭头切换可见光、远紫外和地球全景。键盘 `[` 和 `]` 也可切换模式，方向键调整取景，`Home` 回中并恢复 1×。

需要时点 **校准指向**，再点 **拍摄** 或按 `E`。曝光完成后，可在回看面板查看和下载模拟观测的 PNG 照片。选择 **返回驾驶** 退出望远镜。

## 设置与引导

在 **设置** 中切换简体中文或英文、分别开关音乐和音效，以及开关动作特写。随行无人机的引导可在游戏内 **操作手册** 中重新开启。
