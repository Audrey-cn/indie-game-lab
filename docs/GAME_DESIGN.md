> 本文档从 **产品玩法设计、局内外数值经济、3D 渲染性能优化与多端响应式交互** 四个维度，系统梳理《月面采集站（Lunar Field Station）》如何在一个 **`1.81 MB`（Gzip `806 KB`）零外部请求的离线单文件 HTML** 中，承载三大差异化核心玩法与实时 3D 载具改装系统。

## 1. 三大核心模式与玩家体验分层

项目围绕「同一套 120Hz 6 轮月球车物理底盘 + 同一套 WebGL 2 PBR 渲染管线」，延展出三种节奏互补、资产高度复用的游戏模式：

| 模式 | 核心定位 | 单局时长 | 核心循环与爽点 |
| :--- | :--- | :--- | :--- |
| **完整任务 2.0（Campaign 2.0）** | 沉浸式叙事探索 + 基地基建 | 5–8 分钟 | 轨道空降 → 采集晶样/地质勘测 → 建造中继站/观测站护盾穹顶/太阳能磁轨 → 应对太阳耀斑与微陨石 → `[Q]` 地质声呐破译 3 处遗迹 → **地球望远镜拍照彩蛋** → 火箭点火升空 |
| **深空搜打撤 · 肉鸽远征（Extraction Roguelite）** | 风险回报博弈 + 构筑成长 | 2–5 分钟/波 | 开放月面盆地（4 种随机地貌）→ 节奏 QTE 暴击采矿 + 电磁风暴圈收缩压迫 + 野外应急中继站/跳台/陨石核 → 三选一战术卡牌构筑 → 返回着陆区**安全撤离**或**加注深潜** |
| **星际磁吸竞速 · 狂野轨道（Orbital Mag-Lev GP）** | 高速多巴胺街机竞速 | 2 分钟/3 圈 | 3 张专属 3D 地貌赛道（星港霓虹都市 / 赤峡熔岩矿区 / 天穹反重力 360° 倒立星环）→ 5 档渐进加速 + 甩尾漂移/斜坡滚筒蓄气 → 拾取**氦-3 能量瓶**续杯氮气 → 紫金脉冲爆发 & 写实撞毁击飞特写 → 冲线彩带领奖台 |

## 2. 局内外循环与激励经济模型

### 2.1 跨模式通用货币与中长线目标
- **统一货币（机库通用矿币 `CR`）**：战役遗迹/彩蛋/火箭通关、搜打撤撤离收益、竞速名次/击毁/特技赏金全部汇入同一本地持久化账户（`localStorage`）。
- **视觉化高价值目标（3D 实时变形机库）**：
  - `L-07 先锋探索者`（初始均衡型）
  - `V-12 猎隼疾速艇`（320 CR，流线尾翼 + 推进 `+22%` + 飞跃/加速门收益 `+30%`）
  - `T-88 泰坦重装矿机`（640 CR，重型推矿铲 + 货舱 `+3` + 磁吸 `+35%` + 每波护盾）
  - `X-00 星环迷你飞碟`（彩蛋悬浮碟体，零阻悬浮 + 竞速漂移回气 `×1.5`）
- **降低体验门槛的转化设计**：
  - **免费试驾 1 局**：未解锁载具支持在机库内一键开启 1 局完整体验，先让玩家感受数值与外观质变，再激发攒币解锁动力；
  - **悬赏契约系统**：提供可量化的短周期任务（如暴击采矿、高连击、跨波次深潜），缩短“下一笔大额矿币”的心理距离。

### 2.2 局内风险-回报与正反馈（Juice）
- **搜打撤模式**：引入低矮柔和的 `2.2m` 收缩电磁风暴边界 + 右下角雷达紫色虚线圈，既保持真实月面开阔视野，又给玩家清晰的撤离紧迫感；野外应急中继站可将风暴推远并回盾，形成“贪矿 vs 撤离”的动态博弈。
- **竞速模式**：取消无脑挂机回气，改为漂移/尾流/氦-3 能量瓶/特技主动蓄气；加速期间吃瓶可持续回充氮气延长爆发，加速结束衔接 `2.2s–2.6s` 高惯性滑行尾段，配合 4 层非电子化物理撞击音效与炭黑金属碎片特写，保证高速驾驶的连贯爽感。

## 3. 极限单文件工程架构与性能优化

在**零外部 CDN、零运行时网络请求**的苛刻约束下，通过四项核心工程决策将全套 3 模式 3D 游戏控制在 **`1.81 MB`（Gzip `806 KB`）**：

1. **0 字节程序化 Web Audio 音频引擎**：
   - 移除 `275 KB` Base64 内嵌音频，改由 Web Audio API 实时合成 `Dm9 → Bbmaj7 → Fmaj7 → Csus4` 四和弦渐进深空环境音、月面晶透琴音、6 轮月壤颗粒物理摩擦声与竞速 4 层物理撞击声；
2. **WebGL 2 自定义 Shader 替代重资产**：
   - **地球光学望远镜**：纯片元着色器实现双层差速云系 + 纬向风带 + 旋涡扩散（curl advection），零额外贴图开销；
   - **月面车辙虚拟分页系统**：`16×16` 稀疏物理页池仅按需分配，显存占用降低 **97%**；
   - **车载能量护盾**：平滑球体 + 陡峭 Fresnel 边缘光（`pow(..., 4.2)`），无内部浑浊遮挡；
3. **防卡顿与 GPU 填充率削减**：
   - 启动阶段执行 `renderer.compile(scene, camera)` 预编译全场景着色器，消除首转视角掉帧；
   - 阴影图与接触阴影节流至 `28ms`（~35Hz），桌面端 `pixelRatio` 上限 `1.35`、全屏 SSAO `occlusionScale` 下调至 `0.38`，片段填充负载下降约 **35%**；
4. **领域分层架构与全自动 QA 回归**：
   - `src/` 按 `core / rendering / simulation / world / ui / audio / assets` 七大领域解耦；
   - 配套 Playwright 10 阶段完整战役回归测试（`lunar-campaign-qa.mjs`）与移动端竖/横屏边界零重叠自动化审计。

## 4. 移动端竖屏与横屏双态响应式设计

针对触控设备（`390×844` 竖屏与 `844×390` 横屏）做了全模式专项适配并通过自动化 `getBoundingClientRect()` 碰撞检测验证（8/8 画面 **0 越界、0 遮挡**）：
- **故事模式**：竖屏将声呐/护盾/遗迹/地球彩蛋栏上移至顶部遥测栏下方换行排列，底部 100% 留空给摇杆与推进/刹车键；横屏则将胶囊条与电台字幕压缩居中，严格夹在左右拇指操作区之间。
- **竞速模式**：触控端自动隐藏桌面快捷键文案，缩小右上角小地图至 `72–74px`，释放左下角摇杆区并将速度表与 `DRIFT / NITRO / SHOCK` 触控圆钮紧凑排布于右侧。
- **3D 机库选车界面**：竖屏采用「上 42% 纯净 3D 展台 + 下 58% 底部抽屉」，横屏采用「左 48% 纯净 3D 展台 + 右 52% 停靠面板」，并自动隐藏背景游戏 HUD，确保移动端选车同样拥有无遮挡的 3D 实时变形展厅体验。
